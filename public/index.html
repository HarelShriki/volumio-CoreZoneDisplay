How to play & add radio stations
  1. Direct Stream URL: Tap + Add / Edit Stations above (or open Settings) to paste any direct audio stream URL (.mp3, .aac, .m3u8, or Icecast link) and test-play it immediately.
  2. Import from Volumio: Tap Load from Volumio My Web Radios to fetch stations from Volumio's built-in My Web Radios library (radio/myWebRadio) for 1-tap playback or saving into a preset slot.

How to play & add Podcasts
  1. Option 1 (Direct RSS Feed): Tap + Add Podcast (RSS URL) above and paste any standard Podcast RSS link. CoreZoneDisplay fetches the latest 10 episodes for instant 1-tap playback.
  2. Option 2 (Volumio Plugin / Spotify Connect): Install the Podcasts plugin inside Volumio to browse shows automatically, or stream podcasts directly from your phone via Spotify Connect.
